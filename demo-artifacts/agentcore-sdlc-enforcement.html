The Platform Enforces the Phase-In

Picture A showed which controls turn on when. This shows how — the platform doesn’t advise the roadmap, it enforces it. A loose dev config is not a policy violation to catch later; it is structurally un-promotable to prod.

ⓘ The best practices aren’t a document teams follow by hand — the platform IS the standard, wired into the paved road. Doing it the easy way and doing it the secure way are the same way. A team can’t ship a prod agent with auth=None any more than they can skip the pipeline.

Promotion is gated — each stage must EARN the next

no direct-deploy into any environment
🔧 Dev isolated cell · zero blast radius
  • auth: None  (safe here)
  • public endpoints
  • synthetic data only
  • guardrail + tags + allow-list ON
⛔Conformance gate
→
PR → synth → policy & image gates → permission handoff. Fails the build if the next stage’s required controls aren’t set.
🪂 Pre-Prod masked data · prod-shaped
  • Custom JWT introduced
  • private connectivity introduced
  • masked / de-identified data
  • full eval suite
✅Evidence gate
→
Eval runs on the DEPLOYED runtime. A human approves the EVIDENCE — fail-closed. No evidence, no promotion.
💎 Prod real PHI · full controls
  • Custom JWT enforced
  • private enforced + egress-filtered
  • real PHI — controls on
  • guardrail fail-closed
⛔ No direct-deploy
Nobody hand-carries a config into a workstream account. Everything flows PR → synth → gates → deploy. A dev shortcut has no path to prod that skips the gates — so it simply can’t drift there.
🔍 Gate fails the build
The conformance check runs at cdk synth, before anything deploys. A prod-targeted stack with auth=None, a public endpoint, or a missing guardrail fails the build — the loose config never reaches real data.
📝 Deployed ≠ usable
Even a deployed agent isn’t usable org-wide until it passes registry intake + human approval. A second net under the drift risk — being deployed doesn’t make it discoverable or callable.
✅ The payoff for Wellmark: you don’t hand teams a security-SDLC standard and hope they follow it. The platform makes the secure path the only path — teams inherit the posture, move fast inside isolated dev cells, and cannot promote a loose config to where it would matter. Fast and safe stop being a tradeoff.
